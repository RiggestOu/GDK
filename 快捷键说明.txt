Epub阅读器 快捷键说明（v1.1.3）
设备：GDK mini（OpenDingux / Esoteric，SDL 1.2）
================================================

【阅读页】
A / ↓         下一页（章末自动跳下一章开头）
B / SELECT     返回（阅读页=退出阅读）
X             书签：从当前页首行摘录；该页已有书签则再按删除
Y             菜单
SELECT（默认） 呼出书签光标（可在「自定义快捷键」改绑；功能名：书签光标）
L1 / R1       下一页 / 上一页
L2 / R2       上一页 / 下一页（兼作组合修饰键）
↑ / ↓ / ← / → 上/下/左/右（左=上一章首，右=下一章首）
START         息屏 / 待机（再按一次恢复；CPU 降频，省电）
电源键         息屏 / 待机（与 START 等效；长按仍由系统关机）

【书签光标模式】（默认 SELECT 进入）
↑ / ↓         换整行
← / →         行内逐字移动（精确选字）
X             以光标为起点摘录 23 字 + ... 加书签
B / SELECT     取消光标

【组合键】（按住修饰键再按主键）
L1+START       强制退出 App（自动保存）
L2+START       强制退出 App（同上）
R1+START       强制退出 App（固定别名）
L1+L2          进入 / 退出图片缩放
R1+R2          进入 / 退出图片缩放（固定别名）
任意肩键+音量  ±50%（L2 为 ±20%，纯音量 ±5%）
圆4 / L1+Y     显示 / 隐藏本说明浮层（功能名：快捷键说明，可改绑）

【图片缩放模式】（L1+L2 或 R1+R2 进入）
按住 L1/R1 + →/A 放大10%   ←/Y 缩小10%   ↑/X 放大1%   ↓/B 缩小1%
不按肩键时方向键平移镜头

【菜单】按 Y 打开：目录 / 书签 / 正文颜色 / 字号 / 亮度 / 退出App / 自定义快捷键 / 返回书架

【自定义快捷键】菜单内 A 重绑、SELECT 复位、←→换槽（每功能最多4套）；冲突会被拦截提示。

【待机省电】息屏即进入待机：背光关闭 + CPU 降最低频，耗电极低；再按 START/电源键恢复。
实验：config.cfg 设 standby_kernel=1 可尝试真正硬件挂起（详见使用说明.md 第六节，开启前请确认电源键能唤醒）。

所有配置 / 书签 / 进度写入 $HOME/.epubreader/（OPK 只读挂载）。
日志：/media/roms/apps/EPUBReader/EPUBReader.log
